# The File Namer 📝

The File Namer is a lightweight, web-based automation tool designed to streamline your coding workflow. It eliminates the friction of manually formatting file names when saving coding challenges locally.

🔗 **[Live Demo Hosted on Netlify](https://thefilenamer.netlify.app/)**

## 💡 The Problem
Manually creating local files for completed CodeWars challenges is tedious. Copying a challenge title requires you to manually type out dashes (`-`) between every single word and append file extensions to make it a valid filename. This repetitive formatting breaks your momentum when trying to quickly set up a new file in your code editor.

## 🚀 The Solution
The File Namer makes this process instant and seamless. You simply paste the raw CodeWars challenge title into the web interface, and it immediately spits out a clean, kebab-case string with a `.js` extension (e.g., `the-code-war-challenge.js`). You can then copy and paste this formatted text straight into your code editor to instantly name and create your JavaScript file.

## ✨ Features
* **Instant Conversion:** Transforms standard challenge titles into web-safe, terminal-friendly file names.
* **Kebab-Case Formatting:** Automatically converts text to lowercase and replaces spaces with dashes.
* **JavaScript Extension:** appends `.js` to the end of the title for instant file creation.
* **Pure Web Interface:** Runs entirely in your browser with zero installation required.
* **Workflow Optimization:** Eliminates repetitive typing so you can archive your solutions faster.

## 🛠️ Tech Stack
* **HTML5:** Structures the clean, minimalist user interface.
* **CSS3:** Styles the layout for a seamless user experience.
* **JavaScript (Vanilla):** Handles the real-time string manipulation and conversion logic.
